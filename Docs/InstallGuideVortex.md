# Skyrim Accessibility Install Guide for Vortex.
1. Install [Skyrim Special Edition](https://store.steampowered.com/app/489830/The_Elder_Scrolls_V_Skyrim_Special_Edition/).
> [!Note]
> Skyrim Anniversary Edition is an update with community mods on top of Skyrim Special Edition.
> It is still the same game version; you can use either of these two editions.
2. Download [SKSE](https://www.nexusmods.com/skyrimspecialedition/mods/30379?tab=files) and install it manually by extracting contents of the archive into the game folder where the .exe files are.
3. Download [nvdaControllerClient](https://download.nvaccess.org/releases/stable/) and extract `nvdaControllerClient.dll` into the game folder where the .exe files are.
> [!Note]
> If you've done all of this correctly, both `skse64_loader.exe` and `nvdaControllerClient.dll` should now be in the same folder as `SkyrimSE.exe`.
4. Download the latest setup of [Vortex](https://github.com/Nexus-Mods/Vortex/releases) and install it where you like.
5. Launch the Vortex setup.
6. Select the folder where Vortex should be installed and press Install. The default folder is fine.
7. Launch Vortex.
8. Use Tab to reach the Login button and press Space.
9. Your browser will open. Log in to Nexus Mods if you are not already logged in.
10. Press the Authorise button.
11. Press the Continue button.
12. Use Tab to reach the Games button and press Space.
13. Use Tab to reach the Search For Games table and press Space.
14. Type Skyrim Special Edition.
15. Use Tab to reach Unmanaged and press Space.
16. Use Tab to reach the Launch button and press Space.
> [!Note]
> You should do this once to generate ini files. You can close the game right after.
17. Open a web browser.
18. Download all required mods from Nexus Mods using the "Install via Mod Manager" button. See [Dependencies](Dependencies.md) for the full list with version notes.
19. Download the latest releases of [Skyrim Accessibility](https://github.com/DioKyrie-Git/SkyrimAccessibility/releases) and [SkyrimTTS](https://github.com/DioKyrie-Git/SkyrimTTS/releases) from GitHub.
20. Use Tab to reach the Downloads button and press Space.
21. Use Tab to reach the Open Folder link and press Space.
22. Move both Skyrim Accessibility and SkyrimTTS archives into this folder.
23. Go back to Vortex.
24. Use Tab to reach the Downloads button and press Space.
25. Use Tab to reach the Install button and press Space.
26. Use Tab to reach the Install button again and press Space.
27. Use Tab to reach the Dashboard button (the list with one item) and press Space.
28. Use Tab to reach the Launch button and press Space.
